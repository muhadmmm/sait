# SAIT — Students Association of Information Technology

A responsive frontend redesign prototype for the SAIT Website Redesign Challenge.

## Design direction

SAIT is presented as a digital home for the IT community rather than a conventional department information site.

- Deep navy + electric blue + cyan visual language
- Large editorial hero with lightweight motion
- Responsive event discovery
- Activity Logger as a first-class student workflow
- Careers, alumni and achievements as structured discovery areas
- Mobile navigation drawer
- Reduced-motion support
- No dependency required for the prototype

## Required challenge coverage

The prototype covers the required Home, About, Association/People, Events, Placements/Careers, Alumni, Achievements/Hall of Fame, Student Activity Logger, Notifications/Announcements concept, and Footer/Contact areas.

The challenge guidelines explicitly require responsive behavior across mobile/tablet/desktop and encourage animations, transitions, hover effects and other modern interactions. The Activity Logger is primarily a UI/UX requirement; a backend is not required for the challenge.

## Run

Open `index.html` directly in a browser or deploy the repository with GitHub Pages, Vercel, or Netlify.

## Tech

HTML, CSS and JavaScript.
